# Pruebas de API - COMCESA Fase 2

Esta carpeta contiene la colección de Postman utilizada para ejecutar pruebas automatizadas de API mediante Newman.

Las pruebas verifican autenticación, disponibilidad de servicios, consultas de inventario, filtros, ordenamiento, paginación y control de acceso.

La colección se integrará al pipeline de GitHub Actions como parte del entregable E11 de Aseguramiento de la Calidad del Software.
